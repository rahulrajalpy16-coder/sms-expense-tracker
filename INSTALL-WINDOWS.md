# Windows

## Recommended — standalone Windows launcher

Use `Windows/SMSExpenseTracker.exe` from the full package. It contains the static application and starts a local service at `127.0.0.1:8787`, then opens Microsoft Edge in an app-style window with a dedicated profile.

No Node.js, Python, IIS, Docker or VPS is required.

## Alternative — install this PWA from your HTTPS subdomain

1. Open the subdomain in Edge or Chrome.
2. Choose **Install app**.
3. Open Settings → **Prepare offline OCR & exports** once while online.
4. Keep encrypted `.smsexp` backups.
